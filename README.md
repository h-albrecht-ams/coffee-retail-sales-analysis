# Coffee Retail Analysis

Exploratory analysis of coffee retail sales data using SQL and Python, developed as a collaborative practice project during the neuefische Data Analytics & AI Bootcamp.

## Project Overview

The project explores coffee retail transaction data to better understand sales performance, customer purchasing patterns, and differences across store locations and product categories.

The analysis combines SQL-based exploration with Python/pandas and was later extended with transaction clustering and Tableau visualizations.

## Tools & Technologies

- SQL
- PostgreSQL
- Python
- pandas
- Jupyter Notebook
- Tableau

## Analysis

The exploratory analysis included:

- Data quality and schema checks
- Data type validation and correction
- Revenue and transaction analysis by store
- Sales and revenue analysis by product category and product type
- Monthly sales trends
- Transaction patterns by hour of day
- Average revenue per unit
- Checks for missing values and duplicate transactions

## Project Structure

- `data/` – source data and derived datasets
- `sql/` – SQL-based data exploration and cleaning
- `python/` – Python exploratory analysis and transaction clustering
- `tableau/` – Tableau workbooks and dashboards

## Collaboration

This project was completed collaboratively as an additional practice project during the neuefische Data Analytics & AI Bootcamp.

My contribution focused on exploratory data analysis using **SQL and Python/pandas**, including data quality checks, data type corrections, and analysis of revenue, transactions, stores, and product categories.

## Purpose

The project provided an opportunity to apply SQL and Python to the same business dataset, compare different approaches to exploratory analysis, and practice working collaboratively across multiple stages of an analytics workflow.
